## 🛠️ How to Navigate This Repository Locally

If you are cloning this repository to review my projects locally, you can switch between courses using Git checkout commands.

### 1. Clone the repository
```bash
git clone (https://github.com/Makundi/Data-Analytic-Programme-ALX.git)
```

### 2. View all available course branches
```bash
git branch -a
```

### 3. Switch to a specific course branch
e.g to check out my Month 1 worklog and foundations assignments:
```bash
git checkout course/01-data-ai-literacy
```
